# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Не выпущено]

### Исправлено

- Проверка браузерного моста теперь различает неверный ключ, отказ источника,
  ошибку HTTP и отсутствие приложения на выбранном порту.
- Служебный ping расширения больше не сдвигает позицию трека назад.
- Фоновая или закрываемая вкладка Яндекс Музыки не может очистить либо заменить
  свежий играющий трек из другой вкладки.
- Изменения порта, ключа и источника автоматически перезапускают движок и сразу
  применяются без ручного цикла «Остановить — Запустить».
- Новый трек отображается сразу, не ожидая завершения сетевого запроса LRC.

### Добавлено

- Сборка формирует два готовых артефакта GitHub Release: Windows EXE и отдельный
  ZIP браузерного расширения.
- Оверлей можно перемещать и изменять его размер за нижний правый угол; размеры
  карточки, полосы и мини-плеера сохраняются независимо.

### Изменено

- Оверлей больше не привязан к главному окну и остаётся видимым после его
  сворачивания в трей.
- Удалены неочевидная блокировка положения и красный индикатор-ромб.
- Внешняя рамка оверлея получила безопасный внутренний отступ и не обрезается
  краями прозрачного окна.

## [0.2.0] — 2026-07-30

### Добавлено

- Графическое приложение на PySide6 и Qt Quick.
- Живой фон, динамическая палитра и карточка текущего трека.
- Мини-оверлей с тремя режимами отображения.
- Управление через системный трей.
- Настройка Telegram, Яндекс Музыки и MTProxy внутри приложения.
- Безопасное хранение секретов через системный credential store.
- Локальный браузерный мост с токеном авторизации.
- Расширение Chrome/Edge только для страниц Яндекс Музыки.
- Мгновенная программная остановка через `asyncio.Event`.
- Сценарии установки, проверки, запуска и сборки Windows EXE.
- Отдельные индикаторы воспроизведения, браузерного моста и сервиса текстов.
- Авторизованная проверка связи с браузерным расширением.
- Точная временная шкала веб-плеера через перехват Media Session.

### Изменено

- Общие браузерные медиасессии больше не принимаются за Яндекс Музыку.
- CLI вынесен в отдельную команду `music-bio-cli`.
- Настройки и Telegram-сессия перенесены в `%APPDATA%\Music Bio`.
- Интерфейс перестроен в графитовом Fluent-стиле с подписанной навигацией,
  одноколоночными страницами настроек и собственными тёмными контролами.
- Белые системные выпадающие списки и резкие hover-состояния заменены
  спокойными QML-компонентами.
- Прогресс и строка песни в приложении обновляются четыре раза в секунду,
  независимо от безопасного интервала Telegram Bio.
- Подписи текущего времени и длительности теперь обновляются вместе
  с временной шкалой трека.
- Активная строка песни перенесена под название трека и показывается полностью.
- Следующая строка текста отображается ниже приглушённым цветом,
  как в интерфейсе Яндекс Музыки.
- Восстановление исходного Bio повторяется при временном разрыве MTProxy
  и не отменяется общим сигналом остановки.
- Команда выхода ждёт завершения восстановления Bio перед закрытием процесса.
- Смена строк текста получила мягкий переход с затуханием и сдвигом.
- Пустой блок текста скрывается у треков без синхронизированных слов.
- Пауза сохраняет трек, обложку, позицию и текущую строку в приложении.
- Мини-оверлей показывает обложку, название, исполнителя и прогресс трека.
- Оверлей получил явную область перемещения и сохранение новой позиции.
- Для Qt Controls принудительно включён единый тёмный Basic-стиль без системных
  белых hover-состояний.
- Поиск LRC проверяет несколько точных версий одного трека и корректнее
  сопоставляет композиции с несколькими исполнителями.

## [0.1.0] — 2026-07-29

### Добавлено

- Получение активного трека через Windows GSMTC.
- Поиск синхронизированного текста в Яндекс Музыке.
- Обновление Telegram Bio с обработкой `FloodWait`.
- Восстановление исходного Bio при остановке и завершении программы.
- Режимы `--dry-run`, `--no-lyrics` и `--no-restore`.
- Загрузка настроек из `.env`.
- Модульные тесты и GitHub Actions.
