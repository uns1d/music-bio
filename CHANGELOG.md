# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] — 2026-07-29

### Добавлено

- Получение активного трека через Windows GSMTC.
- Поиск синхронизированного текста в Яндекс Музыке.
- Обновление Telegram Bio с обработкой `FloodWait`.
- Восстановление исходного Bio при остановке и завершении программы.
- Режимы `--dry-run`, `--no-lyrics` и `--no-restore`.
- Загрузка настроек из `.env`.
- Модульные тесты и GitHub Actions.
