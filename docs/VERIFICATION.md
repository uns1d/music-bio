# Music Bio 2.0 — отчёт проверки

Дата проверки: 31 июля 2026 года.

## Выполнено

```text
python -m compileall src tests main.py
ruff check .
ruff format --check .
pytest
pyside6-qmllint
node --check
pip-audit
uv build
```

Результат:

- Python-компиляция: успешно;
- Ruff: ошибок нет, 29 файлов отформатированы;
- Pytest: 73 теста успешно, 3 Windows GUI-теста пропущены на Linux;
- QML: синтаксических ошибок, неизвестных свойств и проблем Layout нет;
- JavaScript браузерного расширения: синтаксис, передача временной шкалы,
  диагностика подключения и поведение при паузе проверены Node.js-тестами;
- аудит установленного окружения через `pip-audit 2.10.1`: известных
  уязвимостей не найдено;
- wheel и sdist: успешно собраны;
- QML-файлы и SVG-иконка присутствуют в wheel;
- реальные токены, номер телефона, IP MTProxy и session-файлы отсутствуют.

Дополнительно проверено:

- служебный ping не изменяет позицию трека;
- несколько вкладок Яндекс Музыки не перебивают активное воспроизведение;
- закрытие фоновой вкладки не очищает текущий трек;
- ошибки порта и авторизации браузерного моста показываются раздельно;
- wheel содержит QML-интерфейс и SVG-иконку;
- сценарий релиза создаёт отдельные EXE и ZIP расширения.
- оверлей не зависит от видимости главного окна, поддерживает системное
  перемещение и изменение размера и хранит геометрию каждого режима отдельно.

## Проверка на Windows

Windows-тест создаёт интерфейс Qt в режиме `offscreen` и входит в обычный
запуск `pytest`. После переноса файлов нужно выполнить:

```powershell
.\scripts\install.ps1
.\scripts\check.ps1
.\.venv\Scripts\python.exe -m music_bio
```

Последняя команда нужна для визуальной проверки анимаций, системного трея,
оверлея и авторизации реального Telegram-аккаунта.
