# Music Bio 2.0

Живое Windows-приложение, которое показывает текущий трек Яндекс Музыки и
синхронизированную строку песни в Telegram Bio.

## Что изменилось в 2.0

- отдельное приложение на PySide6 и Qt Quick;
- графитовый Fluent-интерфейс и спокойная палитра для каждого трека;
- карточка текущего трека, активная и следующая строки песни,
  живая временная шкала и предпросмотр Bio;
- системный трей и корректная остановка без ожидания таймеров;
- мини-оверлей в режимах «Карточка», «Полоса» и «Мини-плеер»;
- настройка Telegram, Яндекс Музыки и MTProxy внутри приложения;
- секреты в диспетчере учётных данных Windows, а не в открытом JSON;
- строгий выбор источника Яндекс Музыки;
- браузерное расширение только для `music.yandex.ru`;
- восстановление исходного Bio перед полным закрытием процесса.

Оверлей является независимым окном: он остаётся на экране после сворачивания
главного приложения, перемещается за свободную область и изменяет размер за
нижний правый угол. Для каждого из трёх режимов размер запоминается отдельно.

## Строгий источник музыки

Music Bio больше не принимает весь звук из Chrome или Edge за Яндекс Музыку.

Есть два независимых безопасных источника:

1. Официальное приложение Яндекс Музыки определяется по App ID медиасессии
   Windows.
2. Веб-версия работает через локальное расширение, разрешённое только на
   `music.yandex.ru` и `music.yandex.com`.

Расширение отправляет данные на `127.0.0.1` и подписывает запросы случайным
ключом. YouTube, сайты с видео и другие вкладки браузера игнорируются.
При паузе трек остаётся на экране, а позиция и синхронизированная строка
замораживаются до продолжения воспроизведения.

## Требования

- Windows 10 или Windows 11;
- Python 3.11 или 3.12;
- Telegram API ID и API Hash с [my.telegram.org](https://my.telegram.org);
- токен Яндекс Музыки, если нужны синхронизированные тексты.

## Быстрая установка

Откройте PowerShell в корне проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install.ps1
```

Ручной вариант:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

## Запуск приложения

С окном консоли:

```powershell
.\.venv\Scripts\python.exe -m music_bio
```

В фоне без консоли:

```powershell
.\scripts\run.ps1
```

Закрытие главного окна сворачивает Music Bio в системный трей. Для полного
выхода используйте пункт «Выйти» в меню значка Music Bio.

## Первоначальная настройка

Откройте раздел «Подключения»:

1. Введите Telegram API ID, API Hash и номер телефона.
2. Вставьте токен Яндекс Музыки или нажмите «Получить токен».
3. Выберите источник музыки.
4. При необходимости вставьте ссылку `tg://proxy?...` и нажмите
   «Разобрать ссылку».
5. Сохраните настройки и нажмите «Запустить».

При первом входе код Telegram и пароль двухэтапной защиты запрашиваются внутри
приложения. Файл сессии сохраняется в `%APPDATA%\Music Bio`.

## Яндекс Музыка в браузере

Для официального приложения этот раздел можно пропустить.

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `browser-extension`.
5. Откройте параметры расширения.
6. Скопируйте порт и ключ моста из раздела «Подключения» Music Bio.

После этого откройте `https://music.yandex.ru` и включите трек.

На главной странице состояния отображаются отдельно:

- «Браузерный мост» подтверждает, что расширение связано с приложением;
- «Воспроизведение» загорается только после получения настоящего трека;
- «Тексты песен» показывает доступность синхронизированных строк.

Позиция веб-плеера считывается непосредственно из Media Session Яндекс Музыки
и передаётся в приложение каждые 500 мс. Интерфейс обновляет прогресс и строку
песни четыре раза в секунду. Telegram Bio обновляется реже из-за ограничений
Telegram — это не влияет на синхронизацию внутри приложения и оверлея.
Несколько открытых вкладок не перебивают активное воспроизведение: приоритет
получает свежая вкладка, в которой действительно играет трек.

Если музыка играет, но трек не появляется:

1. Запустите Music Bio и оставьте источник «Автоматически» или
   «Браузерное расширение».
2. В разделе «Подключения» нажмите «Копировать ключ».
3. Откройте параметры расширения, вставьте тот же ключ и порт.
4. Нажмите «Проверить связь» — в Music Bio индикатор браузерного моста должен
   стать зелёным.
5. Перезагрузите вкладку `music.yandex.ru` и снова включите трек.

Проверка сообщает причину отдельно: несовпадение ключа, отказ источника, ошибку
HTTP либо отсутствие ответа на выбранном порту. После сохранения нового порта,
ключа или источника запущенный движок перезапускается автоматически.

Обычная медиасессия `chrome.exe` намеренно игнорируется: без расширения
невозможно надёжно отличить Яндекс Музыку от YouTube и других сайтов.

## MTProxy

Можно вставить ссылку целиком:

```text
tg://proxy?server=HOST&port=443&secret=SECRET
```

Сервер, порт и secret сохраняются локально. Перед публикацией скриншотов
скрывайте IP-адрес, номер телефона, API Hash, токены и proxy secret.

## Командная строка

Графическое приложение запускается без аргументов. Старый консольный режим
сохранён:

```powershell
.\.venv\Scripts\python.exe -m music_bio --cli --dry-run --no-lyrics
```

Доступные параметры:

- `--list-sessions` — показать медиасессии и отметить разрешённую;
- `--dry-run` — не изменять Telegram Bio;
- `--no-lyrics` — не обращаться к API Яндекс Музыки;
- `--no-restore` — не восстанавливать исходное Bio;
- `--source desktop|browser|auto` — выбрать строгий источник;
- `--interval SEC` — интервал чтения трека;
- `--min-bio-interval SEC` — минимальный интервал изменения Bio;
- `--template TEMPLATE` — изменить шаблон Bio;
- `--debug` — включить подробные логи.

Для CLI настройки можно по-прежнему передать через `.env`. Пример находится в
файле `.env.example`.

## Проверка

Одна команда выполняет все проверки:

```powershell
.\scripts\check.ps1
```

Или по отдельности:

```powershell
.\.venv\Scripts\python.exe -m compileall src tests
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
.\.venv\Scripts\python.exe -m pytest
```

## Сборка EXE

После успешной проверки:

```powershell
.\scripts\build.ps1
```

Сценарий использует официальный инструмент `pyside6-deploy`. Первая сборка
дольше последующих, потому что устанавливает и настраивает Nuitka.

Готовые файлы появятся в папке `release`:

- `MusicBio-0.2.0-Windows.exe` — приложение;
- `MusicBio-Yandex-Bridge-0.2.3.zip` — расширение Chrome/Edge.

Это два файла, которые нужно прикрепить к релизу GitHub. Пользователь
распаковывает ZIP расширения и выбирает полученную папку через кнопку
«Загрузить распакованное расширение» в Chrome или Edge.

## Где хранятся данные

Публичные настройки и логи:

```text
%APPDATA%\Music Bio
```

API Hash, токен Яндекс Музыки, secret MTProxy и ключ браузерного моста хранятся
через системное хранилище учётных данных. В Git нельзя добавлять:

- `.env`;
- `*.session`;
- содержимое `%APPDATA%\Music Bio`;
- любые токены, коды входа и proxy secret.

## Ограничения

Исходное Bio восстанавливается при обычной остановке, выходе из трея и
обрабатываемой ошибке. При завершении процесса через диспетчер задач,
отключении питания или системном сбое выполнить завершающий код невозможно.
